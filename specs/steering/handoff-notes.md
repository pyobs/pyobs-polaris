# Notes for whoever (human or Claude Code) picks this up next

Standing contributor-guidance doc — process reminders, not a design decision.

- Re-clone/re-check the current branch state before resuming — don't assume the working tree
  matches whatever was last discussed in chat.
- Every acceptance criterion in this project's history means "verified live," not just unit tests
  passing — keep that bar for whatever's next in `TODO.md`.
- If a design turns out to need something not anticipated in `TODO.md`, fix that doc, don't just
  fix the code.
